# Мокапы админки

Исходники артбордов из Design-артефакта «Home MCP Hub — админка». Каждый файл — самодостаточный HTML
с инлайновыми стилями: цвета, шрифты, отступы и размеры в нём точные, разметку можно брать как референс
для компонентов. Обёртки `<x-dc>`, `<helmet>` и `<script src="./support.js">` относятся к редактору канваса —
при переносе игнорировать.

Актуальная версия всегда в самом артефакте; здесь — снимок на момент старта.
